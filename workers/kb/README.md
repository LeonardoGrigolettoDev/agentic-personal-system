# kb — knowledge base + knowledge service

Implements docs/ARCHITECTURE.md §9–§11 and CONTRACTS.md §5. It has two modes:

- **CLI on the host** (`kb ingest|search|stats|maintain`) for populating the base: Obsidian vaults, Markdown, PDF, CSV and transcripts.
- **`knowledge` service** (`kb serve`, compose container) for the HTTP API and the **MCP server for Hermes**.

## How it works

```
file / API → parser (frontmatter, #tags, [[links]], PDF pages, SRT) → heading-aware chunks (~350–500 tok)
          → embeddings qwen3-embedding:0.6b (LiteLLM embed-local, 1024d) → Postgres (documents/chunks)
search    → pgvector cosine + full-text 'pt_unaccent' → Reciprocal Rank Fusion
context   → rules/constraints > decisions > project > memories > documents, greedy within the token budget
```

- **Idempotent:** an unchanged `content_hash` skips the document and doesn't re-embed it. `--prune` marks missing files as `deleted`.
- **Abstract URIs:** `obsidian://Pessoal/03 Áreas/x.md`, `file://<label>/x.pdf` and `storage://media/...`. Host paths are never stored.
- **Tenant isolation:** it refuses to ingest the `Nitro` vault outside `--tenant nitro`, and `Pessoal` outside `pessoal`. Every search filters by tenant.
- **Memory (§11):** scope `global|domain|project`, lifecycle `temporary|important|persistent|deprecated`. A memory at cosine ≥ 0.92 to an existing one supersedes it, keeping the history. `kb maintain` expires and cleans up.

## CLI

```bash
make kb-ingest tenant=pessoal path=~/Obsidian/Pessoal            # or: uv run --project workers/kb kb ingest ...
make kb-ingest tenant=nitro path=~/Obsidian/Nitro domain=engineering
uv run --project workers/kb kb ingest --tenant pessoal --dry-run ~/Documentos/livros
make kb-search tenant=pessoal q="metas de estudo"
make kb-stats
make kb-maintain
```

## API (`http://knowledge:8080`, host `127.0.0.1:8092`, `Authorization: Bearer $KNOWLEDGE_API_KEY`)

| Endpoint | |
|---|---|
| `POST /v1/search` | `{tenant, query, domain?, k?, include_shared?}` |
| `POST /v1/context/compile` | `{task, tenant, domain?, project?, budget_tokens, format: json\|markdown}` → Task Context §9 |
| `POST /v1/memories` · `GET /v1/memories` · `POST /v1/memories/search` · `POST /v1/memories/{id}/deprecate?tenant=` | memory |
| `POST /v1/ingest` | `{tenant, source_uri, title, content, source_type, domain?, metadata?}`: transcripts and notes from edge/agents |
| `POST /v1/maintain` · `GET /v1/stats` | maintenance |
| `/mcp` | MCP Streamable HTTP. Tools: `knowledge_search`, `compile_context`, `memory_save`, `memory_search`, `ingest_note` |
| `GET /healthz` · `GET /readyz` | no auth |

## ENV

| Var | Default | |
|---|---|---|
| `KNOWLEDGE_API_KEY` | — (required for serve) | generated by `make env` |
| `KNOWLEDGE_TENANTS` | `nitro,pessoal,shared` | the ceiling of tenants this instance serves |
| `KB_DATABASE_URL` | built from `.env` (`aios@127.0.0.1:$PG_HOST_PORT`) | |
| `LITELLM_BASE_URL`, `KB_LITELLM_KEY` | `http://127.0.0.1:4000` | |
| `KB_EMBED_MODEL` / `KB_EMBED_MODEL_NAME` / `KB_EMBED_DIM` | `embed-local` / `qwen3-embedding:0.6b` / `1024` | changing the model means re-embedding |
| `STORAGE_BACKEND`, `STORAGE_LOCAL_ROOT`, `STORAGE_S3_*` | `local`, `data/storage` | `storage://` (R2/Railway Bucket via `s3`) |
